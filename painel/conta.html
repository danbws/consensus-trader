Binance (cripto)

O robô usa uma chave de API: uma senha que deixa ele negociar, mas nunca sacar. Ela fica salva só neste computador.

  1. No app ou site da Binance: Perfil > Gerenciamento de API > Criar API (tipo "gerada pelo sistema").
  2. Marque só Ativar leitura e Permitir negociação spot e de margem. Nunca marque "Permitir saques".
  3. Em restrição de IP, prefira Restringir apenas a IPs confiáveis e coloque o IP desta internet.
  4. Copie a API Key e a Secret Key e cole abaixo. A Secret Key só aparece uma vez na Binance.

Alpaca (ações, conta de papel)

Conta de teste com dinheiro fictício. Só funciona chave de papel: chave de conta real é recusada. Elas ficam salvas só neste computador.

  1. Entre em app.alpaca.markets e confira que está em Paper (canto superior esquerdo).
  2. Na página inicial, em API Keys, gere as chaves e cole as duas abaixo.
  3. Depois de conectar, apague o arquivo onde você guardou as chaves, principalmente se a pasta sincroniza com a nuvem.

Interactive Brokers (ações, conta de papel)

É a corretora do dinheiro real (planejamento, seção 3). Por enquanto o robô só aceita a conta de papel dela: login de conta real é recusado na hora. Nenhuma senha da IBKR passa pelo robô: você faz o login no próprio programa da IBKR.

  1. Instale o IB Gateway (versão "Stable", do site da Interactive Brokers) neste computador.
  2. Abra, escolha IB API e Paper Trading, e entre com o seu usuário (a conta de papel aparece depois que a conta real é aprovada).
  3. No Gateway: Configure > Settings > API > Settings: marque Enable ActiveX and Socket Clients, desmarque Read-Only API, porta 4002, e em Trusted IPs deixe só 127.0.0.1.
  4. Ligue o Auto restart (em Lock and Exit). Uma vez por semana a IBKR pede o login de novo, com o aviso no app IBKR Mobile.
  5. Clique em Conectar e usar a IBKR. A carteira de consenso passa a ser montada lá, do zero, com US$ 1.000.

Dividendos para o relatório de imposto (Flex Query)

As compras e vendas o robô grava sozinho. Os dividendos e o imposto retido nos EUA vêm de um relatório da IBKR: no Portal do Cliente, Desempenho e Relatórios > Consultas Flex, crie uma consulta de Atividade com a seção Transações em Dinheiro (formato XML, data aaaaMMdd) e ative o Serviço Web Flex para gerar o token.

Telegram

O robô manda cada compra, venda e trava para o seu Telegram, e você pode consultar e intervir por comando. Só a sua conversa é atendida: mensagem de qualquer outra pessoa é ignorada.

  1. No Telegram, procure @BotFather (com o selo azul de verificado) e mande /newbot.
  2. Escolha um nome (ex.: Meu Robô de Trade) e um usuário terminado em bot.
  3. O BotFather responde com um código (números, dois-pontos e letras). Ele é a senha do bot: não mande para ninguém.
  4. Abra o seu bot novo e toque em Iniciar (ou mande /start).
  5. Cole o código abaixo e clique em Ligar Telegram. Chega uma mensagem de teste no seu Telegram.
